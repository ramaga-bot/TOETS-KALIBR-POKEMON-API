Pokémon API Script

Een Phython-script dat Pokemon-gegevens ophaald via [PokeAPI](https://pokeapi.co), verwerkt en wegschrijft naar CSV en JSON

## Wat doet het script?

1. Vraagt hoeveel Pokemon je wilt ophalen .
2. Haalt de lijst met Pokemon op bij PokeAPI.
3. Haalt per Pokemon de details op, met een voortgangsmelding.
4. Verwerkt de gegevens tot een overzichtelijke tabel.
5. Schrijft het resultaat weg naar `pokemon.csv` en `pokemon.json`.
